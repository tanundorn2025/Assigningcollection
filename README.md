# วิเคราะห์การจ่ายงานจัดเก็บลงพื้นที่ (พนักงาน × อำเภอ)

Dashboard หน้าเดียวสำหรับดูว่างานจัดเก็บ (นับเป็นจำนวนสัญญา) ถูกแบ่งให้พนักงานแต่ละคนอย่างไร แยกรายอำเภอ
เพื่อหาปัญหาเรื่องภาระงานไม่สมดุล การลงพื้นที่ซ้ำซ้อน และอำเภอเล็กที่กระจายอยู่ทั่ว

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้า Dashboard (ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย ฝังข้อมูลไว้ในไฟล์แล้ว) |
| `jobs.json` | ข้อมูลดิบ 148 รายการ: `employee`, `district`, `jobs` (ถอดจากตารางต้นฉบับ) |
| `data.py` | ข้อมูลเดียวกันในรูปแบบ Python ไว้ตรวจยอดรวม |

## วิธีใช้
เปิด `index.html` ในเบราว์เซอร์ (ต้องต่ออินเทอร์เน็ตเพื่อโหลด d3 จาก CDN)
หรือเปิดผ่าน GitHub Pages: Settings → Pages → Deploy from branch → `main` / root

## อัปเดตข้อมูล
ข้อมูลฝังอยู่ในบรรทัด `const JOBS = [...]` ใน `index.html` ให้แทนที่ด้วยเนื้อหาใหม่ของ `jobs.json`
(รูปแบบ `[{"employee": "...", "district": "...", "jobs": 12}, ...]`) ตัวเลขสรุปและกราฟคำนวณใหม่เองทั้งหมด

## ตรวจความถูกต้อง
ยอดรวมต่อคน: 218 / 385 / 136 / 345 / 185 รวม 1,269 สัญญา ใน 66 อำเภอ ตรงกับตารางต้นฉบับ
(`python3 -c "from data import *; ..."` ดู `data.py`)

## ข้อจำกัด
- นับจำนวนสัญญาเท่านั้น ไม่รวมมูลค่า ระยะทาง อายุหนี้ หรือผลการจัดเก็บ
- เกณฑ์ "อำเภอเล็ก" (≤5 สัญญา), "ลงน้อย" (≤2 สัญญา), "อำเภอใหญ่" (>50) เป็นค่าที่ผู้วิเคราะห์กำหนด แก้ได้ในโค้ด
- ข้อมูลถอดจากภาพตาราง ควรสุ่มตรวจเทียบกับต้นฉบับก่อนใช้ตัดสินใจ
